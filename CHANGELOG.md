# Changelog

Toutes les modifications notables de ce projet seront documentées dans ce fichier.

## [2.0.0] - 2024-01-15

### Ajouté
- Architecture FastAPI moderne
- Serveur intégré avec `integrated_server.py`
- Interface Katula dynamique améliorée
- Support multi-base de données (SQLite/PostgreSQL)
- Services ML intégrés
- Documentation API automatique avec Swagger
- Système d'authentification JWT
- Routes API structurées
- Services métier modulaires

### Modifié
- Restructuration complète du backend
- Amélioration de l'interface utilisateur
- Optimisation des performances
- Gestion d'erreurs améliorée

### Corrigé
- Problèmes de connexion base de données
- Erreurs d'import des modules
- Configuration CORS
- Chargement des données frontend

### Sécurité
- Ajout de l'authentification JWT
- Variables d'environnement sécurisées
- Validation des données d'entrée
